n this end-to-end project, I  build  Health Network's data platform from the ground up: setting up free Azure, Postgres (Neon), and Blob Storage accounts, building fully metadata-driven ADF pipelines that ingest from multiple source systems, and loading data through the bronze, silver, and gold layers of a medallion architecture in Databricks. Along the way we integrate Key Vault for secrets, build control and audit tables in Azure SQL DB to drive and log every pipeline run, implement both full-load and incremental/merge load logic, connect ADF and Databricks to GitHub for a real CI/CD workflow, send custom pipeline summary emails with Logic Apps, and finish with a Databricks dashboard plus a Genie agent for natural-language querying. Everything used here — data, code, slides, and a detailed PDF — is linked below so you can do the entire hands-on yourself.
